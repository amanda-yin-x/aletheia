# Refund operations

Use the current refund policy for eligibility and approval decisions. Retain the legacy SOP only as conflict evidence; it cannot authorize a refund.

Before `issue_refund`, verify the 30-calendar-day delivery window, approval requirements, payment-rail capability, sanctions state, duplicate-refund state, order version, and exact customer-confirmed amount. Treat the action as proposed until the tool result confirms execution.

When evidence is incomplete or inconsistent, leave state unchanged and return the missing fact, controlling source, and next reviewer action.
